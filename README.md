# Программа для создания паролей

Создаёт пароли разной длины из символов, которые вы выбирите.

--

##  Возможности

- Генерация символов с помощью движения мыши;
- Генерация символов с помощью шума звуковой карты (в разработке);

--

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/DedePomer/PWCreater.git
cd REPO_NAME
```

--

## Используемые технологии

- Языки: C#, XMAL;
- Фреймворки: WPF
- Паттереы: MVVM
